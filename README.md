## 📦 Installation

### Prerequisites
- a go ompiler
- make

### Step-by-step Guide

```bash
# Clone the repository
git https://github.com/alishadan/Scraper.git
# Navigate to the project directory
cd Scraper

# Run make
make

# Run the program
./build/app
```
